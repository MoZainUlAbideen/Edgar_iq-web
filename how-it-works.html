Grounding is the whole point.

A language model will answer a financial question whether or not it actually knows the answer. EdgarIQ is built around one constraint: every figure it states has to be traceable to a real sentence in a real filing, enforced by code and not just asked for in a prompt.

Architecture

Filings are indexed once, offline. Every question then runs through four agents, and the same evaluation harness that guided development guards the result.

Running it live, on free hosting

The demo is a real service, not a recording. A few decisions keep it honest and affordable.

Submit, then poll
A full answer takes tens of seconds, longer than a request should stay open. The page posts a question, gets a job id, and checks back until the answer is ready. One worker and a bounded queue mean a busy moment returns a clear “try again” instead of a hang.
Limits that protect the quota
Each visitor gets a small hourly allowance and the whole demo has a daily cap, so one curious script can’t use up the model quota for everyone.
Cold starts handled in the open
Free hosting sleeps when idle. The page wakes it on load, shows its status in the corner, and keeps the recorded answers working in the meantime.
The index remembers its embedder
Vectors only compare with vectors from the same model. The index records which embedder built it, and the server refuses to start if the one it is configured with doesn’t match.

Tech stack, and why

SEC EDGAR REST API

Free, official, no scraping. Filings come straight from the source with no intermediary to introduce errors.

Gemini embeddings · Ollama locally

Gemini serves the hosted demo; Ollama’s nomic-embed-text runs the same pipeline offline. General-purpose embedding models rank narrative text differently from figure-dense text, which turned out to matter.

Groq · openai/gpt-oss-120b

Fast inference for the reasoning-heavy parts: planning, drafting, and critiquing each question.

Custom hybrid retrieval

Semantic search plus metadata filtering. A specific filing date always overrides a semantic guess once one is mentioned in the question.

FastAPI · Render

A small typed API with job queue, rate limits, and a CORS allowlist, deployed from a single blueprint file.

Static site · Vercel

This page is plain HTML, CSS and JavaScript with self-hosted fonts. No framework, no build step, nothing to break.

Four real bugs, found and fixed

Not a list of features. A record of what actually broke, how it was caught, and what fixed it.

Found by a live filing test

Currency symbols split from their values

What broke: SEC table markup sometimes puts a “$” in its own cell, separate from the number. Row normalization silently truncated the real value and kept the bare symbol.

The fix: Merge symbol-only cells into the adjacent value before column-width normalization runs, so the number survives.

Found by a live pipeline run

The critic was judging evidence it never saw

What broke: The drafter’s context included filing-date labels; the critic independently rebuilt its own context without them, then flagged correct citations as “unsupported.”

The fix: One shared context-formatting function, used by both agents, so the critic always sees exactly what the drafter saw.

Found by the eval harness

Semantic search couldn’t tell quarters apart

What broke: Several quarters describe the same disclosure in nearly identical language. A question naming a specific filing date still retrieved the wrong one, since the date lives in metadata, not the chunk text.

The fix: Detect a filing date in the question and filter retrieval to that filing before ranking by similarity. Pass rate went from 29% to 86% to 100%.

Found while building the hosted index

The wrong embedder ran without any error

What broke: A build meant for Gemini quietly used the local model because an environment variable never reached the process. The index was valid but mislabeled, and searching it with the other model would have returned plausible, wrong chunks.

The fix: Indexes now record which embedder built them. Scripts read it back instead of trusting configuration, the packager refuses a mismatched index, and the server won’t start on one.
