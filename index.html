Reading filings at scale breaks in three specific ways

Each of these is a real failure mode this project hit, diagnosed, and fixed — not a hypothetical.

Numbers get lost in translation

Filing tables split a dollar sign into its own cell, separate from the value. A naive parser silently truncates the actual figure and keeps the symbol.

Confidence isn’t the same as correctness

A language model will answer smoothly whether or not the source actually says what it claims. Fluency gives no signal about whether a number is real.

The right quarter is buried in ten similar ones

Every filing repeats the same disclosure, worded almost identically, with different numbers each time. Search has to know the difference — semantics alone can’t.

What EdgarIQ actually does

Six stages, each one accountable for a specific part of getting the answer right.

01

Ingest

Pull 10-K and 10-Q filings directly from SEC EDGAR’s public API.

02

Parse

Strip layout noise; keep only tables that actually carry financial data.

03

Retrieve

Hybrid semantic and metadata search — a specific date always beats a guess.

04

Draft

Answer using only retrieved excerpts, citing the filing for every figure.

05

Verify

A numeric check confirms every figure actually appears in the source.

06

Critique

A second pass flags any claim the evidence doesn’t clearly support.
